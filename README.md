# 🚗 Databricks Car Sales Analytics Platform

This project was developed for the **Databricks Free Edition Hackathon (November 2025)**.  
It predicts car prices using machine learning and provides business insights through SQL dashboards and visual analytics.

🎥 **Demo Video:** [Watch on Loom]
(https://www.loom.com/share/1a6397072686437984b5617dba524d8b)
---

## 🧠 Key Features
- 99.28% prediction accuracy (R² = 0.9928)
- Real-time predictions using Random Forest (100 trees)
- End-to-end PySpark pipeline (ETL, feature engineering, modeling)
- Interactive dashboards in Databricks SQL
- Delta Lake for data storage

---

## 🛠️ Tech Stack
- Databricks (Free Edition)
- PySpark
- SQL
- Delta Lake
- Random Forest Regressor
- Python 3.10

---

## 📊 Key Insights
- Year of manufacture: 23.4% price influence  
- Engine size: 21.6%  
- Car age: 20.6%

---

## 💼 Business Impact
- Buyers can validate fair prices  
- Sellers can price competitively  
- Dealerships can optimize inventory
